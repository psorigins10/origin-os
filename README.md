# ORIGIN OS

ORIGIN OS is a long-term personal exploration into how computers work, starting from hardware and CPU architecture and progressing toward operating systems, networking, security, and eventually AI/ML systems.

The project is currently in its exploration and learning phase.

Rather than beginning with a predetermined feature set, ORIGIN will evolve as I learn more about computer architecture, operating systems, systems programming, and machine learning.

The goal is to understand the layers beneath modern computing by eventually implementing them myself and experimenting with ideas of my own.
